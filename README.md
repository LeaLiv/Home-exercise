# 📚 Home Exercise - C# Programming Assignment

A comprehensive C# programming exercise project divided into multiple parts, demonstrating various programming concepts and problem-solving skills.

## 📋 Overview

This repository contains a multi-part home exercise project in C#, showcasing different programming techniques, algorithms, and data structures. Each part focuses on specific learning objectives and practical implementations.

## 🏗️ Project Structure

```
Home-exercise/
├── PartA/           # First part of the exercise
├── PartB/           # Second part of the exercise
├── PartC/           # Third part of the exercise
├── PartD/           # Fourth part of the exercise
├── files/           # Additional files and resources
└── .gitignore       # Git ignore rules
```

## ✨ Features

- 📖 **Multi-Part Structure**: Organized into distinct learning sections
- 💡 **Problem Solving**: Various algorithmic challenges
- 🎯 **Practical Implementation**: Real-world programming scenarios

## 🛠️ Installation

### Prerequisites

- .NET SDK (version 6.0 or higher recommended)
- Visual Studio 2022 or Visual Studio Code with C# extension
- Git

### Setup

1. Clone the repository:
```bash
git clone https://github.com/LeaLiv/Home-exercise.git
cd Home-exercise
```

2. Open each part separately or the entire solution:
```bash
# For individual parts
cd PartA
dotnet restore
dotnet build

# Repeat for PartB, PartC, PartD
```

## 🚀 Running the Exercises

### Running Individual Parts

Each part can be run independently:

```bash
cd PartA
dotnet run
```

```bash
cd PartB
dotnet run
```

```bash
cd PartC
dotnet run
```

```bash
cd PartD
dotnet run
```

### Using Visual Studio

1. Open the solution file in each part directory
2. Set the desired project as startup project
3. Press F5 or click "Start Debugging"
